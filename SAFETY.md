# Safety And Ethical Use

This repository is for authorized, defensive evaluation of synthetic or locally owned code. It must not be used to execute unknown patches on a credentialed workstation, expose private repositories through MCP tools, or represent public fixtures as confidential benchmark data.

All included codebases, issue records, documentation, traces, and database rows are fictional and public-safe. The project does not contain customer code, private prompts, credentials, undisclosed tests from another organization, or fabricated external contributions.

The evaluator's path checks, executable allowlist, environment filtering, timeouts, output limits, and network-disabled policy reduce accidental exposure. They do not make the process runner a hardened sandbox. Genuinely untrusted code requires an independently isolated, disposable environment.
