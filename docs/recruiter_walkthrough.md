# Recruiter Walkthrough

## Five-minute path

1. Read the task catalogue in `README.md` to see six languages and task types.
2. Open `tasks/performance_optimisation/go-dedupe-index/task.yaml` to inspect a complete contract.
3. Compare its baseline, golden patch, and intentionally wrong patch.
4. Review `mcp_servers/toolkit.py` for bounded local tool behavior.
5. Review `src/mcp_rl_lab/verifier.py` for candidate isolation and verification order.
6. Open a generated episode under `reports/` to see tool, test, benchmark, and reward evidence together.
7. Read `TEST_REPORT.md` for commands and actual local quality-gate status.

## What this demonstrates

- Unfamiliar-codebase discovery through structured tools
- Cross-language test design and golden reference work
- Deterministic evaluator construction
- Defensive subprocess and patch handling
- Clear separation of candidate and evaluator assets
- Evidence-oriented engineering documentation
